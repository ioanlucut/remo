### Remo

- Remo is a web-based app which simulates an automation process regulation using a PID controller, which communicates with Process value (sensor) and actuator(command) remote through web services.
- 1.0

### How do I get set up?

- Make a clone of the project
- Deploy it on tomcat.
- Start it.
